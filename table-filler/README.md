# Excel表格填写工具

> 原始开发时间：2025-08

## 项目简介

这是一个用于将发货明细表数据按模板表格式进行整理和填写的Python工具。支持一对多关系的数据匹配、列映射配置，并能够处理未匹配数据的特殊情况。

## 功能特性

- 📊 支持Excel文件（.xlsx, .xls）的读取和写入
- 🔄 一对多关系的数据匹配和处理
- 🎯 灵活的列映射配置（支持1对1和1对2映射）
- 📝 保持模板表的格式和结构
- ⚡ 图形化用户界面，操作简单直观
- 🔄 处理未匹配数据（保留映射列数据，其他留空）
- 📁 自动生成带时间戳的输出文件
- 💾 映射配置保存和读取功能（JSON格式）
- 🗂️ 支持批量处理相同的映射配置

## 安装说明

### 系统要求
- Windows操作系统
- Python 3.7或更高版本

### 安装步骤

1. 克隆或下载项目文件
2. 安装依赖库：
   ```bash
   pip install -r requirements.txt
   ```

## 使用方法

### 1. 启动程序
```bash
python excel_filler.py
```

### 2. 操作步骤

#### 步骤1：选择文件
- 点击"选择文件"按钮选择发货明细表
- 点击"选择文件"按钮选择模板表

#### 步骤2：选择Sheet
- 从下拉列表中选择对应的sheet

#### 步骤3：配置匹配列
- 选择发货明细表的匹配列（允许重复值）
- 选择模板表的匹配列（必须唯一）

#### 步骤4：配置列映射
- 选择发货明细表的列
- 选择模板表的目标列1（必填）
- 选择模板表的目标列2（可选，用于一对二映射）
- 点击"添加映射"按钮
- 可以添加多个映射关系

#### 步骤5：保存/加载配置（可选）
- **保存配置**：点击"保存配置"按钮，将当前映射关系保存为JSON文件
- **加载配置**：点击"加载配置"按钮，从JSON文件恢复映射关系
- **清空映射**：点击"清空映射"按钮，快速清除所有映射关系

#### 步骤6：开始处理
- 点击"开始处理"按钮
- 等待处理完成
- 处理完成后会弹出提示，询问是否打开导出文件夹
- 点击"是"可自动打开文件夹并选中生成的文件

## 数据处理规则

### 匹配成功
- 模板表中的一条记录对应发货明细表中的多条记录
- 按模板表格式生成多行数据
- 保留所有映射列的数据

### 匹配失败
- 发货明细表中的数据在模板表中找不到匹配
- 仅保留映射列的数据
- 模板表中的其他列留空
- 仍然生成新行，保持格式一致性

## 注意事项

1. **数据备份**：处理前请备份原始文件
2. **列名匹配**：确保列名准确无误
3. **匹配列唯一性**：模板表的匹配列值必须唯一
4. **文件格式**：支持.xlsx和.xls格式
5. **输出文件**：自动生成带时间戳的文件名

## 常见问题

### Q: 程序无法启动？
A: 请检查Python环境和依赖库是否正确安装

### Q: 文件选择后没有反应？
A: 请确认文件格式是否正确，文件是否被其他程序占用

### Q: 处理结果不正确？
A: 请检查匹配列和列映射配置是否正确

### Q: 大数据量处理很慢？
A: 程序支持大数据量处理，但处理时间会随着数据量增加而增长

## 技术支持
