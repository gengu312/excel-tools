# Excel表格填写工具需求文档

## 项目概述

本工具用于将发货明细表中的数据按照模板表的格式和顺序进行整理和填写，支持一对多关系的数据匹配和列映射。

## 功能需求

### 1. 文件操作
- **选择发货明细表**：包含发货数据的Excel文件
- **选择模板表**：作为格式模板的Excel文件
- **生成填写表**：输出新的Excel文件

### 2. Sheet选择
- 从发货明细表中选择需要处理的sheet
- 从模板表中选择作为格式参考的sheet

### 3. 匹配列配置
- **发货明细表匹配列**：选择用于匹配的关键列（此列允许重复值）
- **模板表匹配列**：选择用于匹配的目标列（此列值必须唯一）

### 4. 列映射配置
- **手动列映射**：允许用户手动配置发货明细表列与模板表列的对应关系
- **映射类型**：
  - 一对一映射：一个明细列映射到一个模板列
  - 一对二映射：一个明细列映射到两个模板列
- **列名处理**：支持明细表和模板表列名不一致的情况

### 5. 数据处理规则

#### 5.1 匹配成功的情况
- 模板表中的一条记录可能对应发货明细表中的多条记录（一对多）
- 按模板表的顺序排列数据
- 保持模板表的格式和结构

#### 5.2 匹配失败的情况
- 当发货明细表中的数据在模板表中找不到匹配值时：
  - 保留明细表中通过映射配置需要复制的特定列数据
  - 模板表中其他未映射的列数据保持为空
  - 仍然生成新行，保持模板表的格式结构

#### 5.3 数据完整性
- 保留发货明细表中的所有相关数据
- 确保数据对应关系正确
- 处理一对多关系时的数据展开

## 技术规格

### 输入要求
- 支持Excel格式：.xlsx, .xls
- 支持多sheet文件
- 支持中文列名和特殊字符

### 输出格式
- 输出文件格式：.xlsx
- 保持模板表的所有格式（样式、字体、边框等）
- 文件命名：填写表_时间戳.xlsx

### 性能要求
- 支持处理大数据量（万级记录）
- 处理时间应在合理范围内
- 提供处理进度反馈

## 用户界面需求

### 1. 文件选择界面
- 发货明细表选择按钮
- 模板表选择按钮
- 文件路径显示

### 2. Sheet选择界面
- 下拉列表显示可用sheet
- 实时预览sheet内容

### 3. 列配置界面
- 匹配列选择区域
- 列映射配置表格
- 添加/删除映射按钮
- 映射关系预览

### 4. 处理进度界面
- 进度条显示
- 处理状态信息
- 错误提示

## 异常处理

### 1. 文件异常
- 文件不存在或无法访问
- 文件格式不支持
- 文件被其他程序占用

### 2. 数据异常
- 匹配列为空值
- 模板表匹配列存在重复值
- 列名不存在或拼写错误

### 3. 处理异常
- 内存不足
- 磁盘空间不足
- 权限不足

## 使用流程

1. **启动程序**
2. **选择发货明细表**
3. **选择模板表**
4. **选择对应的sheet**
5. **配置匹配列**
6. **配置列映射关系**
7. **开始处理**
8. **查看结果文件**

### 正常场景
