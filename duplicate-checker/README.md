# Excel重复数据检测工具

> 原始开发时间：2025-07-24

这是一个用于检测Excel表格中存在相同但包含多余空格的数据的工具。

## 功能特点

- 🔍 **智能检测**：自动识别Excel表格中某一列存在的相同但包含多余空格的数据
- 📊 **可视化界面**：提供友好的图形用户界面，操作简单直观
- 📈 **详细报告**：显示原始值、清理后值、出现次数和具体行号
- 💾 **结果导出**：支持将检测结果导出为Excel文件
- 🧹 **数据清理**：一键清理数据中的多余空格

## 安装要求

- Python 3.6+
- pandas
- openpyxl
- tkinter（通常随Python自带）

## 安装步骤

1. 确保已安装Python 3.6或更高版本
2. 安装依赖包：
   ```bash
   pip install -r requirements.txt
   ```

## 使用方法

1. 运行程序：
   ```bash
   python excel_duplicate_checker.py
   ```

2. 在打开的界面中：
   - 点击"选择Excel文件"按钮，选择要处理的Excel文件
   - 在"选择要检测的列"下拉框中选择需要检测的列
   - 点击"开始检测"按钮进行检测

3. 查看结果：
   - 检测结果会显示在下方的表格中
   - 包含原始值、清理后值、出现次数和行号信息

4. 导出或清理：
   - 点击"导出结果"可将检测结果保存为Excel文件
   - 点击"清理数据"可生成清理后的Excel文件

## 使用场景

- 数据清理：发现并处理数据录入时产生的空格问题
- 数据质量检查：确保数据的一致性
- 重复数据识别：找出因空格差异而被误认为不同的重复数据

## 示例

假设Excel表格中有以下数据：
```
张三
张三 
 张三
李四
李四  
```

工具会识别出：
- "张三"、"张三 "、" 张三" 实际上是同一个值
- "李四"、"李四  " 实际上是同一个值

## 注意事项

- 支持.xlsx和.xls格式的Excel文件
- 程序会将所有数据转换为字符串进行处理
- 清理操作会去除字符串首尾的空格，但保留中间的空格
- 建议在清理数据前先备份原始文件
