# XLS文件支持说明

## 问题描述

如果您在使用Excel重复数据检测工具时遇到"打不开xls文件"的问题，这通常是由于缺少必要的依赖库导致的。

## 解决方案

### 方案一：安装xlrd库（推荐）

1. 打开命令行（CMD或PowerShell）
2. 运行以下命令安装xlrd库：
   ```bash
   pip install xlrd
   ```
   
   如果网络较慢，可以使用国内镜像：
   ```bash
   pip install xlrd -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

3. 重新启动程序即可正常读取xls文件

### 方案二：转换文件格式

如果不想安装额外的库，可以将xls文件转换为xlsx格式：

1. 用Microsoft Excel打开xls文件
2. 点击"文件" → "另存为"
3. 在"保存类型"中选择"Excel工作簿(*.xlsx)"
4. 保存文件
5. 使用转换后的xlsx文件即可

### 方案三：使用在线转换工具

如果没有安装Excel，可以使用在线转换工具：
- 搜索"xls转xlsx在线转换"
- 上传xls文件并下载转换后的xlsx文件
- 使用转换后的文件

## 技术说明

### 为什么会出现这个问题？

- **xls格式**：这是Excel 97-2003使用的老格式，需要专门的xlrd库来读取
- **xlsx格式**：这是Excel 2007及以后版本使用的新格式，使用openpyxl库即可读取

### 程序已做的优化

我们的程序已经进行了以下优化：

1. **自动检测文件格式**：程序会根据文件扩展名自动选择合适的读取引擎
2. **友好的错误提示**：如果缺少xlrd库，程序会显示详细的安装指导
3. **多重兼容性**：支持.xls、.xlsx等多种Excel格式
4. **错误处理**：提供详细的错误信息和解决建议

### 依赖库说明

| 库名 | 用途 | 支持格式 |
|------|------|----------|
| openpyxl | 读写xlsx文件 | .xlsx |
| xlrd | 读取xls文件 | .xls |
| xlwt | 写入xls文件 | .xls |
| pandas | 数据处理 | 通用 |

## 常见问题

### Q: 安装xlrd后仍然无法读取xls文件？
A: 请确保：
1. xlrd版本正确（建议2.0.0+）
2. 重启程序
3. 检查文件是否损坏

### Q: 提示"文件被其他程序占用"？
A: 请关闭Excel或其他正在使用该文件的程序。

### Q: 文件格式不正确？
A: 请确认文件确实是Excel文件，不是其他格式的文件。
